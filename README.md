# Aplikasi Transpose Chord Otomatis

Aplikasi berbasis web untuk **mentranspose chord lagu secara otomatis** langsung dari teks lirik. Dibuat dengan **HTML, Tailwind CSS, dan JavaScript**, mendukung transpose naik dan turun hingga 12 langkah. Chord akan terdeteksi dari teks dan disesuaikan secara otomatis.

## Fitur

- Deteksi otomatis chord dari teks atau lirik.
- Transpose naik dan turun (1–12 langkah).
- Tampilan gelap (dark mode) modern.
- Responsive dan ringan.
- Cocok untuk pemain musik dan arranger.

## Cara Menggunakan

1. Salin lirik lagu yang mengandung chord ke dalam kolom input.
2. Masukkan jumlah langkah transpose yang diinginkan (misal: 2).
3. Klik tombol **"Transpose Naik"** atau **"Transpose Turun"**.
4. Lirik dengan chord yang sudah di-transpose akan muncul di bawahnya.

## Contoh Input

```
C        G        Am  
Ku tatap langit biru  
F        C        G  
Di antara awan putih  
```

## Hasil (Transpose +2)

```
D        A        Bm  
Ku tatap langit biru  
G        D        A  
Di antara awan putih  
```
